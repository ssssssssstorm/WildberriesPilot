# Демо-режим

MarketPlacePilot работает только на искусственных данных. Демо имитирует рабочую очередь менеджера Wildberries: вопросы, отзывы, диалоги, возвраты, подготовку черновиков, передачу человеку и подтверждение действий. Все изменения сохраняются локально в SQLite отдельно для каждого пользователя Telegram.

В демо нет WB API, LLM, платных сервисов и реальной отправки сообщений покупателям. Логика решений построена на понятных сценариях и шаблонах, поэтому интерфейс не называет её нейросетью.

В реальной версии источник данных заменит адаптер официального WB API, а обработка текстов сможет использовать LLM. Доменная логика и Telegram-сценарий при этом останутся независимыми от конкретного подключения. Решения по возвратам и другие рискованные действия потребуют подтверждения человека.

Публичное демо на бесплатном Render использует временную файловую систему: SQLite-сессии будут восстановлены из seed-данных
после перезапуска, redeploy или остановки сервиса. Endpoint `GET /healthz` не требует секретов, не меняет демо-данные и
может использоваться внешним мониторингом для проверки доступности.
